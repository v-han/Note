# 介绍
**AOP**(Aspect Oriented Programming)面向切面编程。
在不动原始设计的基础上为其进行**功能增强**。
# 内容
**连接点**(JoinPoint)：程序执行过程中需要被增强的位置。
**切入点**(Pointcut)：需要进行增强的**连接点**，使用表达式匹配。
**通知**(Advice)：在**切入点**执行的操作。
**切面**(Aspect)：描述**通知**和**切入点**的对应关系。
