# 定义
若随机过程 $\{N(t), t \ge 0\}$ 满足：
1. **初值为零**： $W_0 = 0$ 。
2. **路径连续**： $t \rightarrow W_t$ 是连续的。
3. **独立增量**。
4. **增量服从正态分布**
	对任意 $0 \le s < t$ ，增量 $W_t - W_s \sim N(0, t - s)$ 。
# 数学特性
**均值**： $E(W_t) = 0$ 。
**方差**： $D(W_t) = t$ 因为 $W_t = W_t - W_0 \sim N(0, t)$ 。
**协方差**： $Cov(W_s, W_t) = min(s, t)$ 。
