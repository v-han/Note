# 定义
若随机过程 $\{N(t), t \ge 0\}$ 满足：
1. **起点**： $N(0) = 0$ 。
2. **独立增量性**：在不相交的时间区间 $[s_1, t_1], [s_2, t_2], ...$ 内，事件发生的次数 $N(t_1) - N(s_1), N(t_2) - N(s_2), ...$ 相互独立。
3. **平稳增量性**：增量 $N(t + \tau) - N(t)$ 的分布只依赖时间长度 $\tau$ ，与起点 $t$ 无关。
4. **稀有性**：在极短的时间 $\Delta t$ 里：
	发生 $1$ 次事件的概率： $P(N(\Delta t) = 1) = \lambda \Delta t + o(\Delta t)$ ，
	发生 $\ge 2$ 次事件的概率： $P(N(\Delta t) \ge 2) = o(\Delta t)$ 。(即可忽略不计)。
则 $N(t)$ 是强度为 $\lambda$ 的泊松过程，且满足：
$$
P(N(t) = k) = Poisson(\lambda t) = e^{-\lambda t} \frac{{(\lambda t)}^k}{k!}, k = 0, 1, 2, ...
$$
# 特性
**无记忆性**：对事件间隔 $T_n$ ，有 $P(T > t + s | T > s) = P(T > t)$ 。
**泊松过程的叠加**：独立泊松过程 $N_1({\lambda}_1), N_2({\lambda}_2)$ 叠加后仍是泊松过程，强度为 ${\lambda}_1 + {\lambda}_2$ 。
**泊松过程的分解**：泊松过程 $N(\lambda)$ 可分解为强度为 $\lambda p$ 和 $\lambda (1 - p)$ 的泊松过程。
# 数字特征
均值： $E[N(t)] = \lambda t$
方差： $Var(N(t)) = \lambda t$
协方差：
$$
Cov(N(s), N(t)) = \lambda min(s, t)
$$
相关性由事件重叠长度决定。
时间间隔 $T_n$ ：独立同分布， $T_n \sim Exp(\lambda)$ 。
等待时间 $W_n$ ： $W_n \sim \Gamma(n, \lambda)$ ，密度 $f_{W_n}(t) = \lambda e^{-\lambda t \frac{{\lambda t}^{n - 1}}{(n - 1)!}}$ 。
事件次数： $N(t) \sim Poisson(\lambda t)$ 。
