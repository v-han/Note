# 介绍
中断的优先级：
1. 除法错，溢出中断，软件中断。
2. 不可屏蔽中断。
3. 可屏蔽中断。
4. 单步中断。

在收到中断信息时，CPU要根据中断信息找到要执行的处理程序。CPU根据8位的中断向量表找到相应的中断处理程序的入口地址。

中断过程：
1. 从中断信息中取得中断类型码。
2. 将标志寄存器的值入栈(保护标志位)。
3. 设置标志寄存器的第8位TF和第9位IF的值为0。
4. CS的内容入栈。
5. IP的内容入栈。
6. 读取中断处理程序的入口地址，并设置IP和CS。
