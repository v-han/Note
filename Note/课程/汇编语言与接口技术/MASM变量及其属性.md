# 介绍
变量是存储器中某个数据区的名字，在指令中可以作为操作数。
变量定义伪指令可以为变量申请固定长度的存储空间，并将对应变量进行初始化。
# 定义方式
伪指令格式：
[变量名] 伪指令初值表
# 说明
1. 变量名表示初值表首元素的逻辑地址，即用这个符号表示地址，常称为符号地址。当变量名没有时，汇编程序将直接为初值表分配空，无符号地址。
2. 初值表用逗号分割，主要由数值常量，表达式或?(表示初值不确定，即未赋初值)或DUP(重复初值)组成。

DUP的格式如下：
重复次数 DUP(要重复的值)

3. 可以使用DB/DW/DD/DF/DQ/DT来为控制变量主存空间大小。
DB：给变量分配一个字节。
DW：给变量分配一个字(8086的一个字是16位)。
DD：给变量分配一个双字。
DF：给变量分配3字。
DQ：给变量分配4字。
DT：给变量分配10字。
