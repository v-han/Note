# 介绍
**文法**(Grammar)是一种用有限条产生式规则描述语言结构，并通过这些规则生成语言中所有合法句子的形式化描述工具。
# 内容
从一个**开始符号**出发，按照[[文法形式定义|文法]]规定的**产生式规则**，不断替换语法变量，最终得到只包含**终极符**的字符串。这些生成的字符串就是该文法所描述语言中的[[句子与句型|句子]]。

所有能够从**开始符号**推导得到的句子组成该文法产生的[[语言]]。
