# 介绍
**Flutter容器与布局组件**用于控制子组件的尺寸、位置、排列方式、间距和滚动行为。
# 使用方式
常用的**基础容器**：**Container**(通用容器)，**SizeBox**(设置固定宽高或间距)，**Padding**(设置内边距)，**Center**(子组件居中)，**Align**(控制子组件的对齐方式)，**Card**(卡片式容器)，**SafeArea**(避开系统状态栏等区域)。

常见的**布局组件**：**Row**(水平排列)，**Column**(垂直排列)，**Stack**(层叠排列)，**Wrap**(自动换行排列)，**Expanded**(填充主轴方向分配到的剩余空间)，**Flexible**(弹性分配空间)，Spacer。
