# 介绍
**QLineEdit**中控制回显模式的**枚举类**。
# 使用方式
**QLineEdit::EchoMode**有以下的取值。

| 枚举                                | 含义                                                |
| :-------------------------------- | :------------------------------------------------ |
| QLineEdit::<br>Normal             | 正常模式  <br>输入什么就显示什么，默认就是这种方式                      |
| QLineEdit::<br>Password           | 密码模式  <br>不显示实际输入的字符，而是以小圆圈代替，这样别人就无法看到输入的字符      |
| QLineEdit::<br>NoEcho             | 无回显模式  <br>不会显示任何字符（连掩码符号都没有），既无法看到输入内容，也无法得知输入长度 |
| QLineEdit::<br>PasswordEchoOnEdit | 正在输入时按正常模式显示，当失去焦点时以密码模式显示，也就是显示小圆圈               |
