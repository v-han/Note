# 介绍
使用**lambda匿名函数**来设计Qt中的**槽函数**。
# 使用方法
**CPP**的**lambda表达式**的语法如下：
```cpp
[capture](parameters) option -> reture-type { body }
```

`capture`：捕获列表，用于捕获能够使用的变量，也是**lambda表达式**的引出符。
>`[]`内为空表示不捕获任何变量，`&`表示按引用的方式捕获外部作用域的所有变量，`=`表示按值捕获(只可读，不可更改，要更改要加上`mutable`函数选项)外部作用域的所有变量。
>`[x, y]`表示按值捕获`x`和`y`变量，`[&x, &y]`表示用引用的方式捕获`x`和`y`变量。
>`[=, &x]`表示按值捕获作用域所有变量，但`x`以引用的方式捕获。
>`[this]`捕获当前对象的this指针，就可以使用当前对象的成员变量和成员函数。

`parameters`：参数列表。
`option`：函数选项。
`return-type`：返回值类型。
`body`：函数体。
