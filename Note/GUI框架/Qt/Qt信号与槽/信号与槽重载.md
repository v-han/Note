# 介绍
若**信号函数**与**槽函数**有重载，应该使用以下的方法来连接**信号与槽**。
# 使用方式
使用**函数指针**的方式来连接信号与槽。
```cpp
// 这里使用函数指针能够取到不同参数的函数。
// 使用不同参数的函数指针进行连接达到重载的实现。
void (ClassTest1::*pTestSignal)() = &ClassTest1::testSignal;
void (ClassTest2::*pTestSlot)() = &ClassTest2::testSlot;

connect(classTest1, pTestSignal, classTest2, pTestSlot);
```

此外使用`QOverload`类模板或`qOverload`函数模板，并在`<>`内编写对应的参数类型，这样就能取到不同参数的函数地址。
```cpp
// 类模板方式。
connect(classTest, QOverload<>::of(&ClassTest::testSignal), classTest2, QOverload<>::of(&ClassTest2::testSlot));

// 函数模板方式。
connect(classTest, qOverload<>(&ClassTest::testSignal), classTest2, qOverload<>(&ClassTest2::testSlot));
```
