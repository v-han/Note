# 介绍
Qt的**信号与槽**能够自定义。
# 使用方法
使用自定义条件：
1. 自定义的类要继承`QObject`类。
2. 自定义的类要声明`Q_OBJECT`宏。

自定义一个有信号的类。
```cpp
class ClassTest : public QObject {
	// 包含 Q_OBJECT 宏。
	Q_OBJECT
	
public:
	explicit ClassTest(QObject *parent = nullptr)

// 定义信号
signals:
	// 信号函数不用实现。
	void testSignal();
	// 信号函数能够传递参数。
	void testSignal(QString s);
	
// 定义槽函数，slots 可写可不写(在 Qt5 之后)。
public slots:
	// 槽函数需要实现
	void testSlot();
}
```

> [!NOTE]
> 信号只需要声明不需要实现，且信号的返回值是**void**。

在**槽函数**中使用`sender()`方法能够获得指向信号发送者的指针。
```cpp
// 获取发送信号的对象指针。
QObject* senderObj = sender();

// 使用 qobject_cast 函数模板进行类型转换。
QPushButton* button = qobject_cast<QPushButton*>(senderObj);
```
