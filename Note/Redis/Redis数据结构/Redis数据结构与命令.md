# 介绍
**Redis**是一个**键值型**数据库，其有多种类型的**value**。
# 常用类型
**Redis**的**key**通常只有**字符串**的格式，其可以形成[[Redis key层级格式|层级结构]]。

**Redis**的**value**有以下基本类型：[[Redis String|String]]、[[Redis Hash|Hash]]、[[Redis List|List]]、[[Redis Set|Set]]、[[Redis SortedSet|SortedSet]]。

> [!NOTE]
> 这部分的一些用词混乱，同一词在不同的地方语义不同。
