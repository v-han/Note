# 介绍
**Redis**的安装。
# 使用方式
在**Linux**系统下，根据[这个文档](https://redis.io/docs/latest/operate/oss_and_stack/install/archive/install-redis/install-redis-on-linux/)中的教学安装不同发行版的**Redis**。

> [!NOTE]
> 由于**Redis**没有Windows系统的版本，在Windows中使用[Memurai](https://www.memurai.com/get-memurai)，其兼容**Redis**的生态和协议。
