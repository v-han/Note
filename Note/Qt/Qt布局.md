# 介绍
**Qt**的布局，有**水平布局**(QHBoxLayout)、**垂直布局**(QVBoxLayout)、**网格布局**(QGridLayout)和**表单布局**(QFormLayout)。
# 布局
**水平布局**：将子控件按照从左到右的顺序排列。
**垂直布局**：将子空间按照从上到下的顺序排列。
**网格布局**：按照行与列控制子控件，可以将控件放到第几行第几列，也可以跨越多行多列。
**表单布局**：用于**标签+输入控件**的结构。
