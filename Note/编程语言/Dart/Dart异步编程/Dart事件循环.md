# 介绍
**事件循环**(Event Loop)是**Dart**实现**异步编程**的核心机制，负责管理和调度异步任务，使程序能够在等待异步操作完成时继续执行其他代码。
# 使用方式
**Dart**的**事件循环**主要通过**微任务队列**(Microtask Queue)和**事件队列**(Event Queue)来调度和执行**异步**任务。

**事件循环**的基本执行规则：
1. 首先执行**同步代码**。
2. **同步代码**执行完毕后，优先执行**微任务队列**中的任务。
3. **微任务队列**清空后，从**事件队列**中取出**一个**任务执行。
4. 当前**事件**执行完毕后，再次清空**微任务队列**。
5. 重复上述过程。
