# 介绍
**Dart**的**函数**，是代码**组合**和**复用**的单元。
# 使用方式
**Dart**的函数声明与**C语言**类似，指定**返回值类型**、**函数名称**和[[Dart函数参数|参数列表]]，通过`return`返回函数执行结果。
```dart
int add(int a, int b) {
	return a + b;
}
```

使用`=>`箭头语法定义**箭头函数**，箭头后面只能包含一个表达式，表达式的计算结果会自动作为函数的返回值。
```dart
// 效果和上面的代码一致
int add(int a, int b) => a + b;
```

使用以下的方式定义一个**匿名函数**，**匿名函数**能够作为参数传递。
```dart
// 匿名函数可以赋值给变量，类型是 Function
Function add = (int a, int b) {
	return a + b;
}

// 也可通过箭头函数简化 
var add = (int a, int b) => a + b;
```
