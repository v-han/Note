# 介绍
使用格式化字符串，比使用**字符串拼接**更加方便。
# 使用方式
使用`%`占位符进行占位，使用后面`%`括号里面的内容进行**顺序**填充，这种方法自动进行类型转换。
```python
print("name:%s, age:%s" % ("Tom", 20))
```

> [!NOTE]
> 前面有多少个占位符，后面就要有多少个填充元素。

也可以在字符串前加`f`，在字符串中添加`{}`的形式进行格式化，`{}`可填充变量名和表达式。
```python
name = "Tom"
age = 20
print(f"name:{ name }, age:{ age }")
```

在这种情况下，可以使用`:`来格式化参数的格式。
```python
name = "Tom"
score = 79.999
# score:.1f 表示保留一位小数
print(f"name:{ name }, score:{ score:.1f }")
```
