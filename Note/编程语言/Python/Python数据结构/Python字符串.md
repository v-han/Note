# 介绍
Python中的字符串类型，str来表示。字符串是由每个字符组成的。
# 使用方式
可以使用单引号，双引号来定义字符串。
```python
str1 = 'String1'
str2 = "String2"
```

当需要使用多行的字符串时，需要使用三引号(三个双引号)方式定义。
```python
str3 = """
	this is first line.
	this is second line.
	this is third line.
"""
```

> [!NOTE]
> 当字符串中出现一些特殊字符时可以使用转移字符。
