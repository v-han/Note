# 介绍
变量是程序中用来储存单个数据的容器。
# 使用方式
定义变量`变量名 = 变量的值(字面量)`。
```Python
num = 1
string = "string"
flag = True
```

也可以进行多变量的同时赋值。
```Python
num1, num2 = 1, 2
```

> [!NOTE]
> Python是弱类型语言，在程序运行时可以改变变量的类型。
> ```python
> x = 1
> x = "hello"
> ```
> 这是可行的。但是在项目开发时尽量一种变量仅接受一种类型的值。
