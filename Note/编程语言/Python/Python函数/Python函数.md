# 介绍
**Python**的[[函数与方法|函数]]，即组织好的、可重复使用、有特定功能的代码片段。
# 使用方式
使用`def`关键字来定义函数。定义函数时要给出函数名和[[Python函数参数|参数列表]]，函数名要满足[[Python标识符|命名规范]]。
```python
# 定义函数。
def num_add(a, b):
	return a + b
	
# 调用函数。
num_out = num_add(1, 2)
```

> [!NOTE]
> 函数定义的参数列表和返回语句是可有可无的。

**函数**调用遵循栈(LIFO)的结构。函数嵌套调用时，当前函数会被压入调用栈，然后执行被调用的函数。等嵌套调用的函数执行完毕后将原函数出栈并执行。
