# 介绍
**类型注解**是**Python**种用于明确标注**变量**、**函数参数**和**返回值**的数据类型的方法。使代码更加清晰和易于维护。
**类型注解**只是起到语法提示的作用，并**不会**因为类型不同而报错。
# 使用方式
在定义变量时在变量后面添加变量的具体类型。
```python
a: int = 100
language: str = "Python"

# 数据容器类型的也可以指定数据类型。
list_test: list = [1, "2"]
```

对于数据容器类型的变量，也可以指定容器中元素的类型。
```python
names: list[str] = ["Tom", "Jack"]
names: set[str] = ["Tom", "Jack"]

# 使用 | 来表示能够接收多个类型。
list_test: list[str | int] = ["1", 2]

# 字典类型能够指定键值对的数据类型。
score: dict[str, int] = {"Tom": 90, "Jack": 95}

# 元组类型要指定各个位置的数据类型。
goods: tuple[str, int, int] = ("phone", 4499, 1)
```

> [!NOTE]
> 当为变量赋值了之后，Python解释器会根据变量的值进行**类型推断**出变量的类型。

在函数中，使用上面类似的方式为参数提供注解(提供默认值也会提供注解)，使用`->`为返回值添加注解。
```python
# 表示函数接收两个 int 参数，返回值是 int。
def my_add(a: int, b: int) -> int:
	return a + b
```

> [!NOTE]
> 给[[Python不定长参数|不定长参数]]进行类型注解时，给出的是传入的参数类型。
