# 介绍
使用**自定义模块**将项目分为多个模块使项目结构更加清晰，同时也便于项目的维护。
# 使用方式
每个Python文件都可以作为一个模块，模块的名字就是文件的名字(建议使用[[Python标识符|标识符]]的规范)。

导入模块时会执行模块中的可执行代码。可以使用以下性质，在模块中添加的测试代码在导入时不会被执行。
```python
if __name__ == "__main__":
	test_fun()
```

> [!NOTE]
> `__name__`是Python的内置变量，表示当前模块的名字。若当前Python文件是被执行的文件时，这个变量的值为`"__main__"`，若当前Python文件是被导入的模块，该值为模块名。

使用`__all__`特殊变量来指定`from 模块名 import *`中的`*`通配了哪些功能。
```python
__all__ = ["fun1", "fun2"]
```
