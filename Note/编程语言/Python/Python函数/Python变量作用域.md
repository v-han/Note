# 介绍
Python变量作用的范围，根据变量作用的范围将变量分为**全局变量**和**局部变量**。
**全局变量**：定义在全局，全局可使用。
**局部变量**：定义在函数内部，仅函数内部可以使用。出了作用域就失去作用。
# 使用方式
在函数内部使用变量时默认使用的是局部变量。
```python
num_test = 1

def test():
	# 在函数内创建局部变量。
	num_test = 2

# 全局变量的 num_test 仍是 1。
test()
```

当函数内部想要使用全局变量时，使用`global`来声明使用的是全局变量。
```python
def num_add():
	# 要先声明 a 是全局变量，然后再使用。
	global a
	# 全局中的变量 a 也会加一。
	a += 1
	return a
```


> [!NOTE] Title
> 在函数内部应尽量少的使用全局变量，降低代码维护的成本。
