# 介绍
Python通过**索引**访问数据容器中的元素，并且还能进行切片索引的操作。
这里以[[Python list|列表]]为例。
# 内容
列表可以使用下标索引(和其他语言一样从`0`开始)对指定下标的元素进行操作。
```python
list1[0] = 2
num = list1[0]
```

除了和其他语言一样正向索引，Python的列表还能反向索引，从`-1`开始指最后一位。
```python
list1[-1] = 1
```

可以使用`[开始索引:结束索引:步长]`的形式对列表进行切片索引。
```python
# 以下四种写法功能是相同的
list1[0:4:1]
list1[0:4:]
list1[0:4]
list1[:4]

# 简化成 list1[4] 就变为列表第5个元素了
```

> [!NOTE]
> 在未指定的情况下，开始索引默认是**0**(即开头)，结束索引默认是长度(即能遍历到列表的最后)，步长默认是**1**(即逐个遍历)。

> [!NOTE]
> 如果索引超出范围，会报`IndexError`错误。
