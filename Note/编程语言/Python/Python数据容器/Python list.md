# 介绍
列表(list)是Python数据容器中的一种，可以一次性存储多个元素。
列表可以存储不同类型的元素，**元素有序**，**可以重复**，**可以修改**。
# 使用方式
使用`[]`将元素包围，然后赋值给一个变量来定义列表。
```python
list1 = [1, 2]
```

列表可以使用下标索引(和其他语言一样从`0`开始)对指定下标的元素进行操作。
```python
list1[0] = 2
```

除了和其他语言一样正向索引，Python的列表还能反向索引，从`-1`开始指最后一位。
```python
list1[-1] = 1
```
