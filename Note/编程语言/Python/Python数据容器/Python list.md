# 介绍
**列表**(list)是Python数据容器中的一种[[序列类型]]，可以一次性存储多个元素。
列表可以存储**不同类型**的元素，**元素有序**，**可以重复**，**可以修改**。
# 使用方式
使用`[]`将元素包围，然后赋值给一个变量来定义列表。
```python
# 列表的元素数据类型可以不同
list1 = [1, "string"]
```

列表可以通过[[Python索引|索引]]对元素进行操作。

可以通过的[[Python列表推导式|列表推导式]]生成列表。

使用`del`关键字对列表元素进行删除。
```python
# 删除下标为 1 的元素，后面的元素向前移
del list1[1]
```

使用`in`关键字可以判断元素是否在列表中。
```python
if 1 in [1, 2, 3]:
	print("1 is in the list")
```

使用`*`对列表进行解包。
```python
# *[1, 2, 3] -> 1, 2, 3
new_list = [*list1]
```

使用`+`进行两个列表的拼接。
```python
# [1, 2] + [2, 3] -> [1, 2, 2, 3]
new_list = list1 + list2
```
