# 介绍
**元组**(tuple)是Python数据容器中的一种[[序列类型]]，可以一次性存储多个元素。
**元组**和[[Python list|列表]]差不多，但是**元组**的元素不可修改，**元组**一旦定义完成就**不可修改**。适用于查询结果的展示。
# 使用方式
使用`()`将元素包起来定义一个元组，然后赋值给一个变量。
```Python
# 定义一个元组。
num_tuple = (1, 2, 3)
```

元组也支持[[Python索引|索引]]操作。
