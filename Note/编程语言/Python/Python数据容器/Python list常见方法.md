# 介绍
[[Python list]]的常见方法。
# 使用方式
使用`append()`在列表的尾部添加元素。
```python
# 在列表尾部添加 1 这个元素
list1.append(1)
```

使用`insert()`在指定的索引之前插入元素，后面的元素后移。
```python
# [1, 2, 3] -> [2, 1, 2, 3]
list1.insert(0, 2)
```

使用`remove()`移除列表中**第一个**匹配的值。
```python
# [2, 1, 2, 3] -> [1, 2, 3]
list1.remove(2)
```

使用`pop()`来删除指定索引位的元素(若未指定默认是删除最后一个元素)，后面的元素前移，并将删除的元素返回。
```python
# [1, 2, 3, 4] -> [1, 2, 4]
# num = 3
num = list1.pop(2)
```

使用`sort()`对列表进行排序(列表的数据类型需要一致)，默认是升序。
```python
list1.sort()
```

使用`reverse()`对列表进行反转。
```python
# [1, 2, 3] -> [3, 2, 1]
list1.reverse()
```
