# 介绍
**集合**(set)是Python数据容器中的一种。
**集合**是**无序的**、**不可重复的**，**可修改的**。
# 使用方式
使用`{}`将元素包起来定义一个集合，然后赋值给一个变量。
```python
num_set = {1, 2, 3}

# 定义一个空集合时要使用 set(), {} 定义字典。
num_set2 = set()
```

集合是无序的，不支持**索引**访问。
