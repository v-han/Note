# 介绍
**Rust**中**自动化测试**，用于检测程序的**逻辑**是否有漏洞。
在函数上加上`#[test]`注解是**测试函数**。使用[[Rust断言|断言]]来判断逻辑是否正确。
# 使用方式
在模块内部添加测试模块，在测试模块内编写**单元测试**。
```rust
#[cfg(test)] // 条件编译，只有测试时才编译以下代码
mod tests {
	// 省略测试的预处理代码
	
	#[test]
	fn test_fun() {
		// 省略具体测试
		// 断言结果是否符合逻辑要求
		assert!(res);
	}
}
```

在和**src**目录同目录下创建**tests**目录，在这个目录下编写**集成测试**。
```rust
// 在 tests 目录下的文件默认不编译
#[test]
fn test_fun() {
	// 省略具体测试
	// 断言结果是否符合逻辑要求
	assert!(res);
}
```

使用`test`命令运行测试。测试完成后会显示各个**测试函数**的执行结果，以及失败测试的相关错误信息。
```bash
cargo test
```

> [!NOTE]
> **Rust**测试默认是多线程并行运行，需确定各个测试相互**独立**，且**避免**共享或修改相同的数据、文件等资源。或使用参数将其限制为单线程。
> ```bash
>  cargo test -- --test-threads=1
> ```
