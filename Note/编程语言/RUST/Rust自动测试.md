# 介绍
**Rust**中**自动化测试**，用于检测程序的**逻辑**是否有漏洞。
# 使用方式
在函数上加上`#[test]`标注是**测试函数**。
```rust
#[cfg(test)] // 条件编译，只有测试时才编译以下代码
mod tests {
	// 省略导入部分
	// 仍可以在这部分添加代码作为测试的预处理
	
	#[test]
	fn test_fun() {
		// 具体过程
		
		// 断言结果是否符合逻辑要求
		assert!(res);
	}
}
```

[[Rust断言]]

使用`test`命令运行测试。测试完成后会显示各个**测试函数**的执行结果，以及失败测试的相关错误信息。
```bash
cargo test
```
