# 介绍
**Rust**的**可变引用**。
# 使用方式
在类型前加上`mut`表示该引用数据类型时可变的。
```rust
// 原本的变量也必须是可变的
let mut x = 3;
// &mut i32 表示是可变的引用类型
// &mut x 表示取到 x 的可变引用变量
let y: &mut i32 = &mut x;

// 通过解引用的方式对数据进行操作
*y += 1;
```

> [!NOTE]
> 在任何一个作用域中，只能存在一个可变引用**或**多个不可变引用。
> ```rust
> let mut s = String::from("hello");
> let s1 = &mut s;
> // 不允许再对 s 取引用，以下语句都是不被允许的
> // let s2 = &mut s;
> // let s3 = &s;
> ```

**可变引用**可通过**重新借用**(reborrow)的方式临时降级为**不可变引用**。
```rust
let mut x = 3;
let y = &mut x;
// 此时 z 和 y 都是不可变的引用，在 z 借用结束前都不可修改
let z = &*y;
```
