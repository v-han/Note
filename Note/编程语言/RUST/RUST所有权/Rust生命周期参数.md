# 介绍
使用**Rust生命周期参数**显式标明**生命周期**，帮助编译器进行**借用检查**。
# 使用方式
使用**泛型生命周期参数**确定**返回值生命周期**和**参数生命周期**关系。使用`'`标注**生命周期**，例如`'a`和`'b`表示不同的**生命周期**，然后让编译器进行**借用检查**。
```rust
// 表示 x, y 和返回值受同一种生命周期约束，但并不代表生命周期相同
// 返回值的生命周期由编译器确定，通常是参数中较短的生命周期
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
	if x.len() > y.len() {
		x
	} else {
		y
	}
}

// Rust不知道返回的是 x 还是 y，无法确定生命周期，会发生错误
// fn longest(x: &str, y: &str) -> &str {}
// fn longest<'a>(x: &'a str, y: &'b str) -> &'a str {}
```

> [!NOTE]
> **生命周期参数**只能标注**生命周期**无法改变**生命周期**。
> 可以和[[Rust Trait Bound|Trait约束]]中的`where`方式同时使用**Trait**和**生命周期参数**。

使用`'static`标注**引用**可以在整个程序的持续时间内存活。
```rust
// 字符串字面量可以存活整个程序的持续时间
let s: &'static str = "str";
```

对于使用了**引用**类型的**结构体**，也**必须**使用**生命周期参数**标注。
```rust
// 该结构体的生命周期必须在其引用的变量生命周期之内。
struct ImportantExcerpt<'a> {
	part: &'a str,
}

// 为其实现方法也需要标注
impl<'a> ImportantExcerpt<'a> {}
```
