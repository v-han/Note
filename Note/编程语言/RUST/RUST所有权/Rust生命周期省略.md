# 介绍
**Rust**中编写**生命周期**相关代码时的**省略规则**。
# 使用方式
在满足以下规则后可以不用显式使用**生命周期**。
1. 编译器会为每个**输入**的**生命周期**分配**不同**的**生命周期参数**。
2. 如果只有一个**输入**的**生命周期参数**，该**生命周期参数**会被分配到所有**输出**的**生命周期**。
3. 如果有多个**输入**的**生命周期参数**且其中有`self`相关的**引用**，那`self`的**生命周期参数**会被分配到所有**输出**的**生命周期**。

> [!NOTE]
> 使用这套规则之后仍存在歧义，编译器会报错。
> 
> 当**生命周期**关系涉及返回的[[Rust闭包]]、`impl Trait`等**隐藏类型**时，往往需要显式写出生命周期约束。
