# 介绍
使用**Box**可以将数据存放到堆上。
# 使用方式
可以使用`Box::new`将数据存放在[[Rust Heap|堆]]上，并将地址指针返回。
```rust
// 在 Heap 上存 [1, 2, 3, 4]，并将地址传给 a。
// a 的类型为 Box<[i32; 4]>
let a = Box::new([1, 2, 3, 4]);
```

使用`*`来解引用。
```rust
let x = Box::new(3);
// 让 x 指向的内存数据加一
*x += 1;
```
