# 介绍
所有权是**Rust**的特性，能够让**Rust**无需**GC**(垃圾处理)就可以保证内存安全。
# 所有权
**Rust**会将数据存储到[[Rust Stack|栈]](Stack)和[[Rust Heap|堆]](Heap)上。
所有权规则：
1. 每个值都有一个变量，这个变量是该值的所有者。
2. 每个值同时只能有一个所有者。
3. 当所有者超出[[Rust Scope|作用域]]时，该值将被删除。
