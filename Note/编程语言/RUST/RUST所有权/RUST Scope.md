# 介绍
**变量作用域**(Scope)是程序中某一变量的有效范围。
# 内容
对于一个变量，走出其的**作用域**，**RUST**会自动清理对应的内存。如果该变量拥有[[Rust Heap|堆]]内存数据的**所有权**，在变量离开**作用域**时，**Rust**会自动释放其拥有的堆内存。
```rust
fn main() {
	// s 不可用
	let s = "hello";
	// s 可用
} // s 的作用域结束，s 不再可用
```

> [!NOTE]
> 因此**Rust**中对拥有**堆**内存数据的**所有权**的变量的赋值操作都只是**移动**(Move)，会使原变量失去数据的**所有权**。以防止发生**二次释放**(对同一堆内存释放两次)。
> ```rust
> let s1 = String::from("Hello");
> let s2 = s1; // 此时 s1 失效
> ```

可以使用**克隆**(Clone)避免数据的移动。
```rust
let s1 = String::from("Hello");
// 此时 s2 拥有另一片堆内存的所有权，其数据与 s1 相同。
let s2 = s1.clone();
```
