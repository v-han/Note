# 介绍
变量作用域(Scope)是程序中某一变量的有效范围。
# 内容
对于一个值，走出其的作用域，**RUST**会调用`drop`函数。
```rust
fn main() {
	// s 不可用
	let s = "hello";
	// s 可用
} // s 的作用域结束，s 不再可用
```

对于**复杂数据**类型，将一个变量赋值给另一个变量会发生**移动**(Move)，使原来的变量失效，使其在离开**作用域**的时候不会发生二次释放内存。
```rust
fn main() {
	let s1 = String::from("Hello");
	let s2 = s1; // 此时 s1 失效
	
	// 以下的代码会出现问题，因为 s1 已失效
	// println!("{}", s1); 
}
```

若要复制这个**复杂数据**类型变量的内容而不使原来的变量失效，可以使用**克隆**(Clone)。
```rust
let s1 = String::from("Hello");
let s2 = s1.clone();
```

对于简单标量类型，可以直接使用**复制**(Copy)。
```rust
let x: u32 = 123;
let y = x;
```
