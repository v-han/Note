# 介绍
**Rust**字符串的切片，其本质仍是**字符串**的**不可变**[[Rust引用和借用|引用]]类型(只能有一个可变引用**或**多个不可变引用)。
# 使用方式
使用`[起始索引 .. 结束索引]`(左开右闭)的方式对字符串起切片。字符串的切片范围必须是有效的**UTF-8**字符边界。
```rust
let s1 = String::from("hello");
// & 引用是必须的
// s2 的类型是 &str
let s2 = &s1[0 .. 2];
```

> [!NOTE]
> 如果起始索引是第一个元素可以省略，如果结束索引是字符串的结尾也可以省略，例如`&s1[ .. 2]`，`&s1[2 .. ]`，`&s1[ .. ]`。

字符串切片的类型是`&str`，并不同于字符串的引用类型`&String`。**Rust**中的字符串[[字面量]]是`&str`类型的。
```rust
// 此时 s 的类型为 &str，而不是 &String
let s = "hello";
```

在函数参数中`&str`能够接收`&String`类型的变量(自动转换)，反之不行。
