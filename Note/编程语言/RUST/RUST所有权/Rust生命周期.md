# 介绍
**Rust生命周期**用于确保**引用**在所需的时间内有效。
大多数时候**生命周期**都是隐式的，且可被推断出来的。
# 使用方式
使用**引用**时，**被引用数据**的**生命周期**必须至少覆盖该**引用**的有效使用范围。Rust会使用**借用检查器**(Borrow Checker)比较**作用域**，确保**数据**存活时间长于其**引用**。
```rust
let r; // r 的生命周期开始
{ // x 的生命周期开始
    let x = 10;
    r = &x;
} // x 的生命周期结束
println!("{}", r); // r 的生命周期结束
// x 的生命周期未覆盖其引用 r 的生命周期，故发生错误
```

使用[[Rust生命周期参数|生命周期参数]]来显式标明**生命周期**，帮助编译器进行**借用检查**。
