# 介绍
**RUST**的数据类型，**RUST**是静态编译语言，在编译时需要知道所有变量的类型。
编译器能够基于使用的值推断出变量的数据类型。**但是**当可能输出的类型不唯一时，编译器会报错。
# 更多
**RUST**的数据类型又分为**标量**和**复合类型**。
**标量**：[[RUST整数类型|整数类型]]、[[RUST浮点类型|浮点类型]]、[[RUST布尔类型|布尔类型]]和[[RUST字符类型|字符类型]]四个主要标量类型。
**复合类型**：**RUST**有两种基础的复合类型：[[RUST元组|元组]]和[[RUST数组|数组]]。
