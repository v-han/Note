# 介绍
在**Rust**中对变量重复声明，后声明的变量会**隐藏**之前声明的同名变量。
# 使用方式
后声明的变量**覆盖**前面声明的同名变量。
```rust
let str = "123";
// 后面定义的变量会隐藏前面的变量，且数据类型也可改变
let str = str.len();
```

变量的**隐藏**只会在当前的**作用域**。离开这个**作用域**后，如果外层**作用域**中存在同名变量，就会重新访问外层的变量。
```rust
let x = 3;
{
	let x = 4;
	// 输出为 4
	println!("x is {}", x);
}
// 输出为 3
println!("x is {}", x);
```

> [!NOTE]
> 变量的**隐藏**可以实现变量类型的改变，而使用可变变量改变值的方式不行。
