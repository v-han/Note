# 介绍
**Rust**的**Box智能指针**，指向存储与[[Rust Heap|堆]]上的数据。
# 使用方式
使用`Box::new`将数据存放在**堆**上，并将地址指针返回。
```rust
// 在 Heap 上存 [1, 2, 3, 4]，并将地址传给 a。
// a 的类型为 Box<[i32; 4]>，a 的地址数据在 Stack 上
let a = Box::new([1, 2, 3, 4]);
```

**Box指针**和正常指针一样可以使用[[Rust解引用|解引用]]。
