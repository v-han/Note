# 介绍
**Rust**的**Rc智能指针**(Reference Counting，引用计数)会跟踪一个值的**强引用**数量。当最后一个**强引用**被销毁后，该值就会被清理。
# 使用方式
使用`Rc::new`创建一个**Rc**管理的**堆**上的数据，并返回**Rc指针**。使用`Rc::clone`创建一个指向**同一数据**的新的**Rc指针**，同时增加该数据的**强引用**计数。
```rust
let a = Rc::new(3);

let b = Rc::clone(&a);
```

使用`Rc::strong_count`查看**Rc指针**的**强引用**数量。
```rust
println!("{}", Rc::strong_count(&a));
```

> [!NOTE]
> **Rc指针**的引用计数操作不是**原子性**的，**多线程**下同时操作会出现问题，只适用于**单线程模式**。
> 
> **Rc指针**对于被引用的数据是**不可修改的**。
