# 介绍
**Rust**的常量，具有以下特征：
1. 不可以使用`mut`关键字，常量是不可变的。
2. 使用`const`关键字定义，且必须标注类型。
3. 可以在任何域内进行声明。
4. 只能绑定到**常量表达式**，即编译阶段就可知道的值。
# 使用方式
使用`const`关键字声明常量。
```rust
const MAX: u32 = 100;
```

> [!Note]
> [[命名规范]]：在RUST里使用常量名使用全大写字母，每个单词间用下划线分开。
