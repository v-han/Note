# 介绍
**RUST**的常量，具有以下特征：
1. 不可以使用`mut`关键字，常量是不可变的。
2. 使用`const`关键字定义，且类型必须被标注。
3. 可以在任何域内进行声明。
4. 只能绑定到常量表达式，无法绑定到函数的调用结果和运行时计算的值。
# 使用方式
使用`const`关键字声明常量。
```rust
const MAX: u32 = 100;
```

> [!TIP]
> [[命名规范]]：在RUST里使用常量名使用全大写字母，每个单词间用下划线分开。
