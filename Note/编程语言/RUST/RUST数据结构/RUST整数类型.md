# 介绍
**RUST**的整数类型。
有符号整数以**i**开头，无符号整数以**u**开头。
# 整型类型

| 长度   | 有符号   | 无符号   |
| ---- | ----- | ----- |
| 8位   | i8    | u8    |
| 16位  | i16   | u16   |
| 32位  | i32   | u32   |
| 64位  | i64   | u64   |
| 128位 | i128  | u128  |
| arch | isize | usize |

> [!NOTE]
> `isize`和`usize`类型由程序运行的计算机架构决定。
