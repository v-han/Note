# 介绍
**Rust**的变量。
# 使用方式
声明变量时使用`let`关键字。
```rust
let num = 5;
```

> [!NOTE]
> 默认情况下，变量是**不可变的**(Immutable)，定义完之后就不可变了。
> 不可变的**变量**和[[Rust常量|常量]]也是有区别的。

在声明变量时，加上`mut`关键字就可以使变量可变。
```rust
let mut num = 5;
```

> [!NOTE]
> 可以使用相同的名字声明新的变量，新的变量会[[Rust变量隐藏|隐藏]](shadow)之前声明的同名变量。在之后的代码会使用新的变量。

可以在变量名后面加上对应的[[Rust数据类型|数据类型]]来指定变量的**数据类型**，在未指定数据类型时编译器会自动推导。
```rust
let x: u32 = 123;
```
