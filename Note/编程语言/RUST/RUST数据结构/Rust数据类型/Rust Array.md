# 介绍
**Rust**的**数组**，声明之后长度和类型无法变化。
想让数据保存在栈内存上而不是堆内存上时，或者保证一定数量的元素可以使用数组。
# 使用方式
使用中括号来定义，中间的值用逗号隔开。
```rust
let arr = [1, 2, 3];
```

可以使用`[类型; 长度]`的方式来声明指定类型和长度的数组。
```rust
let arr: [i32; 3] = [1, 2, 3];
```

如果数组中每个元素值都相同可以使用`[要重复的值; 重复次数]`的方式定义。
```rust
let arr = [3; 5];
```

可以和其他语言一样用数组下标访问数组元素。
```rust
let num = arr[0];
```
