# 介绍
前往[该网址](https://rust-lang.org)下载对应系统的**Rust**。在命令行窗口进行简单的配置，直接默认安装即可。
# 使用方式
需要更新时可以使用以下指令进行更新。
```bash
rustup update
```

需要卸载时在命令行输入以下指令。
```bash
rustup self uninstall
```

可以通过以下命令查看RUST的本地文档。
```bash
rustup doc
```

新建`.rs`的文件，编写入口函数`main`。或使用[[Cargo]]构建和运行**Rust**程序。
```rust
fn main() {
	// 具体实现
}
```
