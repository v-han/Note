# 介绍
由**RUST**标准提供，指定一个开始数字和结束数字，`range`可以生成之间的数字(左闭右开)。
# 使用方式
在开始数字和结束数字之间用`..`隔开。
```rust
for num in 1 .. 4 {
	println!("{}", num);
}
```

> [!NOTE]
> 一般情况下，不用加`()`，加了还会报`warning`。
> 
> 但是使用**Range**的方法时需要括起来，类似数学表达式提升处理优先级让编译器知道这是**Range**。

可以使用`rev()`方法将**Range**反转。
```rust
for num in (1 .. 4).rev() {
	println!("{}", num);
}
```
