# 介绍
**Rust**的**文档注释**，用于指导别人如何使用自己设计的`crate`。
# 使用方式
使用`///`对其之后的项目进行**文档注释**，**文档注释**支持**Markdown**的语法。
```rust
/// # Example
/// ```
/// 示例
/// ```
fn funct() {}
```

> [!NOTE]
> 一般使用**Examples**来指导示例，用**Panics**来说明怎么样的使用会导致代码**panic**，用**Errors**来说明怎么样的使用会导致错误及错误的种类，用**Safety**来说明代码的安全情况。
> 
> 在[[Rust测试|测试]]时也会对文档注释的代码部分进行测试，这种测试称为**文档测试**(Documentation Tests)。

使用`//!`整个**crate**或**模块**提供**文档注释**。
```rust
//! 这个模块的整体描述
```

可以使用`pub use`来将较为深层的代码进行重新导出，方便阅读。
```rust
// 阅读者不需要到 user 的文档下就可以直接查看到 User
pub use user::User;
```

使用`cargo doc`会将根据文档注释生成对应的文档。
```rust
cargo doc
```
