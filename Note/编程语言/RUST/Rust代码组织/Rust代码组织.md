# 介绍
**Rust**的代码组织形式。
# 使用方式
**Rust**有以下的项目代码组织形式。
1. [[Rust Package|package]]：**Rust**的项目，由[[Cargo]]进行管理。
2. [[Rust Crate|crate]]：**Rust**编译单元。
3. [[Rust Module|module]]：**Rust**代码模块，用于组织和管理**crate**内部代码。

对于大型项目可以使用[[Rust Workspace|Workspace]]来管理多个**package**。
