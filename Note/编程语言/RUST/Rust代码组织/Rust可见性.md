# 介绍
**Rust**中模块及其内部项的可见性由**可见性规则**控制，默认情况下是**私有的**
# 使用方式
使用`pub`关键字将**模块**、**变量**、**函数**、**结构体**和**枚举类**等变公开。
```rust
pub mod models {}
pub fn funct() {}
```

> [!NOTE]
> **结构体**还需要额外控制其字段的**可见性**。
> ```rust
> pub struct User { 
> 	pub name: String, 
> 	age: u32,  // age 是私有的不可访问
> }
> ```

**子模块**可以使用其**祖先模块**中的项，而**父模块**不能使用**子模块**中**私有项**。
