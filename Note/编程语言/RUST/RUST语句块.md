# 介绍
**语句块**是由一组连续语句组成的整体代码结构。和别的语言不同，**RUST**的语句块也是一个**表达式**，有返回值。
# 使用方式
使用`{}`将语句括在**语句块**中。**语句块**也可以是表达式，有返回值。
```rust
let flag : bool = true;
let num = {
	if flag {
		1
	} else {
		2
	}
}
```

> [!NOTE]
> 语句块会将最后一个表达式作为返回值，所以逻辑上最后一个语句([[Rust if|if]]分支里的也算)要是一个表达式，且不用`;`。
> 
> 在语句块里用用不了`return`关键字。
