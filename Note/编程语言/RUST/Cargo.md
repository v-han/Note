# 介绍
**Cargo**是[[RUST]]的构建系统和包管理工具。安装**RUST**时会同时安装**Cargo**，因此不需要额外的安装。
# 使用方式
使用**Cargo**创建项目。
```bash
cargo new <ProjectName>
```

这样就会创建一个指定名称的**RUST**项目，项目的结构：
- [[Cargo.toml]]
- src目录，用于存放源代码。
- 初始化一个[[Git]]仓库。可以使用`--vcs`不使用或使用其他VSC。
- 其他信息，例如**README.md**和许可证信息等。

使用Cargo构建项目。
```bash
cargo build
```

使用后会出现出现构建目标目录(target)和[[Cargo.lock]]文件。

> [!NOTE]
> 可以加上`--release`选项为发布构建，这样运行速度快，但编译时间会加长。

构建并运行Cargo项目。
```bash
cargo run
```

使用后会构建、编译然后运行项目。若之前编译成功过且代码没有修改，会直接运行二进制文件。

检查项目。
```bash
cargo check
```

使用会检查代码，确保能够通过编译，但是不会生成可执行文件。由于检查比构建运行速度快，可以多使用检查提高效率。
