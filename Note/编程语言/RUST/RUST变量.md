# 介绍
[[RUST]]的变量。
# 使用方式
声明变量时使用`let`关键字。
```rust
let num = 5;
```

> [!NOTE]
> 默认情况下，变量是不可变的(Immutable)，定义完之后就不可变了。
> 不可变的变量和[[RUST常量|常量]]也是有区别的。

在声明变量时，加上`mut`关键字就可以使变量可变。
```rust
let mut num = 5;
```

> [!NOTE]
> 可以使用相同的名字声明新的变量，新的变量会[[RUST变量隐藏]](shadow)之前声明的同名变量。在之后的代码会使用新的变量。
