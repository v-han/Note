# 介绍
控制元素显示隐藏。
# 使用方式
编写`<div>`标签，加上`v-show`属性，根据表达式来控制元素是否显示。
```HTML
<div id="app">
	<!-- 可以使用不同的标签，表达式也可以为变量 -->
	<div v-show="false">this is a example</div>
</div>
```

这样就可以控制元素的显示。

> [!NOTE]
> 本质上是利用标签的`display`属性来控制，实际上还是会渲染。
> 利用这个特性可以设计频繁切换显示隐藏的元素。
# 相关
对比：[[v-if]]不会渲染出来，而v-show还是会被渲染出来。
