# 介绍
RISC-V是一种基于精简指令(RISC)原则的开源指令集架构(ISA)。
[RISC-V基金会网址](https://riscv.org)
# 设计目标
1. 要适合设计各种规模的处理器。
2. 要兼容各种流行的软件栈和编程语言。
3. 要适用于所有实现技术。
4. 能用于高效实现所有微体系结构。
5. 要稳定，基础ISA不会改变。
# 特点
1. 完全[[Creative Common Aribution(CC BY)|开源]]。
2. 模块化设计。
