# 介绍
使用**Keil**创建工程及开始前的配置。
# 开发步骤
打开**Keil**选择指定的芯片。

在工程里添加以下的文件，建议放在**Start文件夹**下方便管理：
**`startup_stm32f10x_md.s`**：[[STM32启动文件|启动文件]](根据芯片选择)。
**`stm32f10x.h`**：STM外设寄存器描述文件。
**`system_stm32f10x.h`**，**`system_stm32f10x.c`**：主要用于配置时钟。
**`core_cm3.h`**，**`core_cm3.c`**：内核寄存器描述文件以及内核配置函数。

在工厂里创建`main.c`文件。
```C
#include "stm32f10x.h"

int main(void) {
	while(1) {}
}

```

> [!NOTE]
> 文件的最后一行是一个空行，否则回编译错误。

这样就建立了STM32的工程，由于还没有引入STM32的库函数，目前就是[[基于寄存器开发]]的项目。可以试试[[STM32点灯项目]]。
