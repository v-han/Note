# 介绍
STM32启动文件，根据芯片的不同选择不同的文件。
# 分类

| 缩写        | 释义        | Flash容量  | 型号          |
| --------- | --------- | -------- | ----------- |
| **LD_VL** | 小容量产品超值系列 | 16-32k   | 100         |
| **MD_VL** | 中容量产品超值系列 | 64-128k  | 100         |
| **HD_VL** | 大容量产品超值系列 | 256-512k | 100         |
| **LD**    | 小容量产品     | 16-32k   | 101/102/103 |
| **MD**    | 中容量产品     | 64-128k  | 101/102/103 |
| **HD**    | 大容量产品     | 256-512k | 101/102/103 |
| **XL**    | 加大容量产品    | 大于512k   | 101/102/103 |
| **CL**    | 互联型产品     | -        | 105/107     |

> [!NOTE]
> 型号前的`STM32f`前缀被省略。
