# 介绍
EXTI(Extern Interrupt，外部中断)可以监测指定[[GPIO]]口的电平信号，当指定的**GPIO**口发生电平变化时，**EXTI**将立即向[[NVIC]]发出中断申请，经**NVIC**裁决之后中断CPU主程序，执行**EXTI**对应的中断程序。
# 相关参数
**支持的触发方式**：上升沿、下降沿、双边沿和软件触发。
支持所有的**GPIO**口，但是相同的Pin口不能同时触发中断(即PA0和PB0不能同时使用，详细看下方图像)。
**通道数**：16个GPIO_Pin，外加PVD输出、RTC闹钟，USB唤醒和以太网唤醒等。
**触发方式**：中断响应和事件响应(触发外设的中断)。

![[EXTI基本结构.png]]
每个**GPIO**的引脚通过[[AFIO]]进行选择后再通到**EXTI**上再发送到**NVIC**上，这就是为什么不能使用相同的Pin口。
