# 介绍
GPIO(General Purpose Input Output)通用输入输出口。
# 相关参数
可配置为8种[[GPIO工作模式|输入输出模式]]。
**引脚电平**：0-3.3v，部分引脚能够容忍5v(可接受5v的输入电压)。
**输出模式**下可控制端口输出高低电平，驱动外设，可模拟通信协议。
**输入模式**下可读取端口的高低电平，实现信号输入。

![[GPIO基本结构.png]]
每个GPIO外设按照GPIOA、GPIOB方式命名的。每个GPIO外设有16个引脚，以GPIOA为例，从PA0到PA15。

内核通过APB2总线对寄存器进行读写实现输出电平和读取电平的功能。

> [!NOTE]
> 因为STM32是32位的，而引脚是只有16个。因此寄存器只有低16位的有对应端口。
