# 介绍
使用标准库开发STM32。

# 开发步骤
使用**Keil**[[STM创建工程|创建一个工程]]，在工程文件夹建立`Start`、`Library`和`Code`等文件夹，复制固件库中的库函数并添加到对应的工程文件夹中。

> [!NOTE]
> 文件夹和工程文件夹是不一样的。一个是文件的实际目录，一个是**Keil**里的工程管理文件夹。

在工程选项中，**C/C++** 中的`Include Paths`内添加包含头文件的目录，在`Define`内定义`USE_STDPERIPH_DRIVER`(表示使用库函数编译)。在**Debug**的选择对应的调试器。

然后[[基于标准库的代码编写|编写]]对应的`main.c`文件。
```C
#include "stm32f10x.h"

int main(void) {
	// 配置时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
	
	// 配置端口
	// 编写端口配置结构体
	GPIO_InitTypeDef GPIO_InitStructure;
	// GPIO 模式
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	// GPIO 端口
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;
	// GPIO 速度
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	
	GPIO_Init(GPIOC, &GPIO_InitStructure);
	
	// 设置高电平
	// GPIO_SetBits(GPIOC, GPIO_Pin_13);
	// 设置低电平
	GPIO_ResetBits(GPIOC, GPIO_Pin_13);
	
	// 用死循环保持状态
	while(1) {}
}

```
