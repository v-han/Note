# 介绍
使用标准库进行STM32的[[STM32中断|中断]]配置。
# 使用方式
为**GPIO**和**AFIO**配置时钟。
```C
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);
```

> [!NOTE]
> **NVIC**是内核上的外设，因此**不需要**额外配置时钟。

配置[[GPIO 标准库配置|GPIO]]的引脚(使用浮空，上拉或下拉输入)。
```C
GPIO_InitTypeDef GPIO_InitStructure;
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
GPIO_InitStructure.GPIO_Pin = GPIO_Pin_14;
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_Init(GPIOB, &GPIO_InitStructure);
```

使用[[AFIO]]对端口进行映射。
```c
GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource14);
```

配置[[EXTI 标准库配置|EXTI]]与[[NVIC 标准库配置|NVIC]]。

编写对应的中断函数，需要到`startup_stm32f10x_md.s`文件找到对应的中断向量。这里由于使用的是**EXTI**的14引脚。
```c
void EXTI15_10_IRQHandler(void) {
	// 判断是否指定的中断源的中断
	if (EXTI_GetITStatus(EXTI_Line14) == SET) {
		// 中断处理函数
		
		// 清除中断标志位，否则代码会死循环
		EXTI_ClearITPendingBit(EXTI_Line14);
	}
}
```

> [!NOTE]
> 中断程序中应该尽量是耗时短的代码，否则主程序会收到严重的阻塞。此外，应避免中断程序和主程序使用同一个函数或外设。
> 所以尽量使用标志位来传递中断的信息。
