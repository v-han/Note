# 介绍
[[NVIC]]的分组方式，整个芯片只能用一种**NVIC分组**。
# 分组方式
**NVIC**有以下的分组方式来设置**抢占优先级**和**响应优先级**。

| 分组方式 | 抢占优先级   | 响应优先级   |
| ---- | ------- | ------- |
| 分组0  | 0位      | 4位，0-15 |
| 分组1  | 1位，0-1  | 3位，0-7  |
| 分组2  | 2位，0-3  | 2位，0-3  |
| 分组3  | 3位，0-7  | 1位，0-1  |
| 分组4  | 4位，0-15 | 0位      |

**抢占优先级**：一段程序运行时，根据抢占优先级进行判断是否抢占，即进行中断嵌套。
**响应优先级**：一段程序结束，根据响应优先级来判断下一个程序。
**抢占优先级**和**响应优先级**均相同时按中断号排队。

**优先级**设置的数值越低表示**优先级**越高，即0的优先级最高。
