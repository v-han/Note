# 介绍
STM是意法半导体公司(STMicroeletronics，简称ST)设计的以[[ARM]] Cortex-M为核心的32位微控制器。
# 开发模式
[[基于寄存器开发]]：对硬件理解深入，但开发和移植不方便。
[[基于标准库开发]]：介于两者之间。
[[基于HAL库开发]]：开发和移植难度低，对硬件的理解浅。

> [!NOTE]
> 此笔记使用的是[[STM32F103C8T]]芯片，[[STM32片上资源|相关资源]]。
