# 调试指令
寄存器与状态查看：
1. **r** ：查看当前 CPU 所有寄存器的值以及标志位。
2. **d** ：查看内存中的内容。
代码执行控制：
3. **t** ：单步执行。
4. **p** ：逐过程执行。
5. **g** ：运行程序，`g`一直运行到程序结束，或`g 0015`运行到指定位置。
代码与内存操作：
6. **u** ：反汇编。将内存中的机器码翻译成你熟悉的汇编指令。
7. **a** ：直接写入汇编指令。  
8. **e** ：修改内存中的数据。`e ds:0 11 22 33`：从 `ds:0` 开始依次写入这些 16 进制数。
退出：
9. **q** ：退出 Debug 环境，回到 DOS 命令行。
