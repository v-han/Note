# 指令介绍
```
DAA;
DAS;
```

进行组合的BCD调整指令。
`DAA`指令的调整方法：
1. 如果AL的低4位在A~F之间或AF为1，则AL <- (AL) + 6H，且置AF为1。
2. 如果AL的高4位在A~F之间或CF为1，则AL <- (AL) + 60H，且置CF为1。
`DAS`指令的调整方法：
3. 如果AL的低4位在A~F之间或AF为1，则AL <- (AL) - 6H，且置AF为1。
4. 如果AL的高4位在A~F之间或CF为1，则AL <- (AL) - 60H，且置CF为1。
# 注意
1. `DAA`和`DAS`指令影响标志位AF，CF，PF，SF和ZF，但不影响OF。
2. `DAA`和`DAS`指令使用时要**分别**紧跟在以AL为目标操作数的加法和减法指令之后。
