# 数据传送指令
1. [[传送指令]]：MOV。
2. [[交换指令]]：XCHG。
3. [[取有效地址]]：LEA。
4. [[装入地址指令]]：LDS，LES。
5. [[标志传送指令]]：LAHF，SAHF。
6. [[表转换指令]]：XLAT。
7. [[堆栈操作指令]]：PUSH，POP。
8. [[符号拓展指令]]：CBW，CWD。
