# 指令介绍
```
CBW;
CWD;
```

`CBW`：将AL中的单字节数符号拓展到AH中。
`CWD`：将AX中的单字节数符号拓展到DX中。

例：
```
MOV AL, 6FH; AL <- 6FH
CBW; AH <- 00H

MOV AL, 0AFH; AL <- 0AFH
CBW; AH <- FFH

MOV AX, 4F0AH; AX <- 4F0AH
CWD; DX <- 0000H

MOV AX, 0EF0AH; AX <- 0EF0AH
CWD; DX <- 0FFFFH
```
