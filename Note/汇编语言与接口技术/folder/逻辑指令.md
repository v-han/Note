# 指令介绍
```
AND dest, src;
OR dest, src;
XOR dest, src;
```

`dest`：目标操作数。
`src`：源操作数。
`AND`：按位与操作，将结果送回`dest`目标操作数中。
`OR`：按位或操作，将结果送回`dest`目标操作数中。
`XOR`：按位异或操作，将结果送回`dest`目标操作数中。
# 注意
1. `dest`目标操作数不能为立即数。
2. `dest`目标操作数和`src`源操作数不能同时为存储单元。
3. 段寄存器不能进行逻辑运算。
