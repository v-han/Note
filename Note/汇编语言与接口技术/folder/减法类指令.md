# 指令介绍
```
SUB dest, src;
SBB dest, src;
DEC reg/mem;
```

`dest`：目标操作数。
`src`：源操作数。
`reg`：通用寄存器。
`mem`：存储单元。
`SUB`：计算`dest`目标操作数数据减去`src`原操作数数据(不带借位CF)，结果放在`dest`目标操作数。
`SBB`：计算`dest`目标操作数数据减去`src`原操作数数据(带借位CF)，结果放在`dest`目标操作数。
`DEC`：将操作数数据减一，再送回该操作数。
# 注意
1. `SUB`和`SBB`指令不允许两个操作数都是存储器操作数。
2. `SUB`和`SBB`指令不允许在两个段寄存器之间相减。
3. `SUB`和`SBB`指令会对标志位(主要是CF，ZF，OF，SF)有影响。
4. `DEC`指令中`reg`和`men`可以为8位和16位的。
5. `DEC`指令操作数不能是立即数。
6. `DEC`指令会影响AF，OF，PF，SF和ZF，但不会影响CF。
7. `DEC`指令将操作数视为无符号数(?存疑)。
