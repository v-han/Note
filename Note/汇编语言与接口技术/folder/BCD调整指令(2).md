# 指令介绍
```
AAA;
AAS;
AAM;
AAD;
```

进行未组合的BCD调整指令。
`AAA`：对[[加法类指令|ADD]]指令运算后AL中的内容进行调整。
`AAS`：对[[减法类指令|SUB]]指令运算后AL中的内容进行调整。
`AAM`：调整[[乘法指令|MUL]]指令的运算结果，使AX中的乘积变为BCD码。
`AAD`：调整[[除法指令|DIV]]指令运算前AH，AL中的除数，以便除法运算所得的商事有效的非组合的BCD数。
# 注意
1. `AAA`和`AAS`会影响 AF与CF，而对OF，PF，SF和ZF没有意义。
2. 除了`AAD`是在除法指令之前，其他的都要在对应的运算指令之后。
