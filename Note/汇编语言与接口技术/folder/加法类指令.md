# 指令介绍
```
ADD dest, src;
ADC dest, src;
INC reg/mem;
```

`dest`：目标操作数。
`src`：源操作数。
`reg`：通用寄存器。
`mem`：存储单元。
`ADD`：将`src`原操作数数据和`dest`目标操作数数据相加(不带进位CF)，结果放在`dest`目标操作数。
`ADC`：将`src`原操作数数据和`dest`目标操作数数据相加(带进位CF)，结果放在`dest`目标操作数。
`INC`：将操作数数据加一，再送回该操作数。
# 注意
1. `ADD`和`ADC`指令不允许两个操作数都是存储器操作数。
2. `ADD`和`ADC`指令不允许在两个段寄存器之间相加。
3. `ADD`和`ADC`指令会对标志位(主要是CF，ZF，OF，SF)有影响。
4. `INC`指令中`reg`和`men`可以为8位和16位的。
5. `INC`指令操作数不能是立即数。
6. `INC`指令会影响AF，OF，PF，SF和ZF，但不会影响CF。
7. `INC`指令将操作数视为无符号数。
