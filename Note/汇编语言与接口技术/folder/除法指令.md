# 指令介绍
```
DIV src;
IDIV src;
```

`src`：源操作数。
`DIV`：进行无符号除法，若进行字或字节相除时，所得的商和余数分别放在AL和AH中；若进行双字或字相除时，所得的商和余数分别放在AX和DX中。
`DIV`：进行有符号除法，若进行字或字节相除时，所得的商和余数分别放在AL和AH中；若进行双字或字相除时，所得的商和余数分别放在AX和DX中。

> [!warning]
> 这里区分8位和16位除法的方式不清楚，之后有空补上。
# 注意
当除法的商超过了存储商的寄存器的表示范围，会产生0号中断。
