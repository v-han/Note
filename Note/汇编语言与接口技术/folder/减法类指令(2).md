# 指令介绍
```
NEG reg/mem;
CMP dest, src;
```

`dest`：目标操作数。
`src`：源操作数。
`reg`：通用寄存器。
`mem`：存储单元。
`NEG`：将操作数数据取补后送回该操作数，即将操作数数据连同符号位逐位取反然后在末尾加一。
`CMP`：将`dest`目标操作数数据减去`src`原操作数数据，结果不送回，但是会更新标志位。通常使用ZF判断是否相等，CF判断大小，然后接上条件跳转指令。
# 注意
1. `NEG`指令中`reg`和`men`可以为8位和16位的。
2. `NEG`指令操作数不能是立即数。
