# 指令介绍
```
MOV dest, src;
```

`dest`：目标操作数。
`src`：源操作数。
将`src`源操作数的数据传输到`dest`目标操作数上。

# 注意
1. `MOV`指令可以传8位和16位数据，这取决于寄存器是多少位的或立即数是多少位的。
2. 不允许使用`MOV`实现两个存储单元间的数据传输。
3. 不能使用CS和IP作为目标操作数，这两个寄存器的内容不能随便修改。
4. 不能在段寄存器间进行数据传输。
5. 不能用立即数作为目标操作数。
6. 不能向段寄存器传输立即数，只能先传输到通用寄存器中再传输。
