# 指令介绍
```
MUL reg/mem;
IMUL reg/mem;
```

`reg`：通用寄存器。
`mem`：存储单元。
`MUL`：进行两个无符号的8位或16位的乘法运算。乘积放在AH，AL或DX，AX中。
`IMUL`：进行两个带符号的8位或16位的乘法运算。乘积放在AH，AL或DX，AX中。

例：
```
MOV AL, NUMBER1; 8位的例子。
MUL NUMBER2; 将AL的内容乘以NUMBER2，乘积放在AX。

MOV AX, NUMBER1; 16位的例子。
MUL NUMBER2; 将AX的内容乘以NUMBER2，乘积低位放在AX，高位放在DX。
```

`IMUL`同理。
# 注意
1. `reg`和`men`可以为8位和16位的。
2. 乘法指令隐含了一个操作数AL或AX，这取决于`reg`和`men`的位数，且输出结果存放的位置AH，AL或DX，AX也取决于这个操作数的位数。
