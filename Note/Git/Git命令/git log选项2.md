# 介绍
限制[[git log命令]]输出的提交信息。
# 选项
下面是一些常用的限制选项。

| 选项                   | 说明                   |
| -------------------- | -------------------- |
| `-<n>`               | 仅显示最近的n条提交。          |
| `--since`，`--after`  | 仅显示指定日期之后的提交。        |
| `--until`，`--before` | 仅显示指定日期之前的提交。        |
| `--authior`          | 仅显示字符串匹配的作者的提交。      |
| `--committer`        | 仅显示字符串匹配的提交者的提交。     |
| `--grep`             | 仅显示字符串匹配的提交说明的提交。    |
| `-S`                 | 仅显示字符串匹配的添加或删除内容的提交。 |

> [!NOTE]
> `--since`，`--until`可以是"2026-07-20"的具体某一天，也可以是"2 years ago"这样相对日期。
