# 介绍
使用该命令查看Git中文件状态。
# 使用方法
可以使用`git status`命令查看Git的状态。
```bash
git status
```

这里可以看到Git的状态，例如[[Git分支]]，**暂存区文件**和**未跟踪文件**以及**已修改文件**。
可以使用添加`-s`或`--short`选项来获得简短输出。
```bash
git status -s
git status --short
```

这样就会将文件的状态和文件名直接列出来(不会显示已提交后未修改的文件)。
`??`：新添加的未跟踪文件。
`A`：新添加到暂存区文件。
`M`：已修改文件。
`MM`：已暂存后又修改过的文件。
