# 介绍
使用该命令删除**工作区**和**暂存区**的文件。
# 使用方法
使用`git rm`命令来删除文件。
```bash
git rm <filename>
```

> [!NOTE]
> 使用该命令会使**工作区**和**暂存区**的文件同时被删除。

如果该文件之前**已修改**，或者已经提交到下一次提交的**暂存区**，使用该命令需要加上`-f`选项(防止已修改的文件被丢弃)。
```bash
git rm -f <filename>
```

如果只是想删除暂存区的文件，而不删除工作区文件(即不让Git继续跟踪)可以加上`--cached`选项。
```bash
git rm --cached <filename>
```

在`git rm`命令后的文件或目录名可以使用[[glob模式]]。
