# 介绍
[[git log命令]]的一些常用选项。
# 选项
下面是`git log`的常见选项。

| 选项                     | 说明                                        |
| ---------------------- | ----------------------------------------- |
| `-p`                   | 按补丁格式显示每个提交引入的差异。                         |
| `--stat`               | 显示每次提交的文件修改统计信息。                          |
| `--shortstat`          | 只显示每次提交的总体修改信息。                           |
| `--name-only`          | 仅在刚提交信息后显示已修改的文件清单。                       |
| `--name-status`        | 显示新增，修改和删除的文件清单。                          |
| `--abbrev-commit`      | 仅显示SHA-1校验和字符中的前几个字符。                     |
| `--relative-date`      | 使用较短的格式显示日期。                              |
| `--graph`              | 以ASCII图形的方式显示分支和合并。                       |
| [[pretty选项\|--pretty]] | 使用其他格式显示提交信息。                             |
| `--oneline`            | `--pretty=oneline`和`--abbrev-commit`合用简写。 |
