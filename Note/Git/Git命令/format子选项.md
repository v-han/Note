# 介绍
[[git log命令]]的[[pretty选项]]的子选项，用于定制显示提交记录。
# 使用方式
在`--pretty`选项后面加上`format`子选项。
```bash
git log --pretty=format:"%h - %an, %ar : %s"
```
# 格式选项
下面是`format`子选项的常用选项。

| 选项  | 说明                  |
| --- | ------------------- |
| %H  | 提交的完整哈希值。           |
| %h  | 提交的简写哈希值。           |
| %T  | 树的完整哈希值。            |
| %t  | 树的简写哈希值。            |
| %P  | 父提交的完整哈希值。          |
| %p  | 父提交的简写哈希值。          |
| %an | 作者名字。               |
| %ae | 作者的电子邮箱地址。          |
| %ad | 作者的修订时间。            |
| %ar | 作者的修订日期，按多久以前的方式显示。 |
| %cn | 提交者的名字。             |
| %ce | 提交者的电子邮箱地址。         |
| %cd | 提交日期。               |
| %cr | 提交日期，按多久以前的方式显示。    |
| %s  | 提交说明。               |
