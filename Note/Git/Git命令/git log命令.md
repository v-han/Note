# 介绍
使用该命令查看提交历史。
# 使用方式
使用`git log`命令查看提交历史。
```bash
git log
```

使用该命令后，Git会按时间列出提交并显示每个提交的校验和，作者信息，提交时间和提交信息。

该命令有很多[[git log选项|参数选项]]，这里只列出一些。
加上`-p`或`--patch`选项可以显示提交引入的差异，使用`-n`选项来显示最近几次的提交。
```bash
git log -p
git log -p -2
```

第二行的命令表示只显示最近2次的提交。

使用`--stat`选项显示文件的总结性变化(只显示文件的变化情况，不展示具体变化)。
```bash
git log --stat
```
