# 介绍
使用此命令将文件放到暂存区。
# 使用方式
使用`git add`命令可以将文件进行跟踪。
```bash
git add <filename>
```

这样可以将指定文件进行跟踪，存放在**暂存区**中。

可以使用正则匹配和`.`来添加文件。
```bash
git add *.c
git add .
```

上面的指令分别表示将**符合`*.c`匹配的文件**和**所有文件**进行跟踪。

> [!NOTE]
> 注意，**已跟踪**的**已修改**文件也需要使用`git add`命令存放在暂存区。
> 
> 可以添加一个[[Git忽略文件]]来配合`git add`命令。
