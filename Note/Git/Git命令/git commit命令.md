# 介绍
使用该命令将暂存区文件提交到Git目录中。
# 使用方法
使用`git commit`命令提交。
```bash
git commit
```

这样会打开[[Git配置]]的文本编辑器，在这个编辑器中会给出一下基础的信息，例如[[Git分支]]信息和提交文件。然后需要在这个编辑器中编写提交信息。
加上`-v`选项可以将更改的diff输出到编辑器中，方便根据更改编写提交信息。
```bash
git commit -v
```

除此之外，使用`-m`选项可以将越过打开编辑器编写提交信息(懒得配置文本编辑器时使用)。
```bash
git commit -m "提交信息"
```

在Git提交后，会给出当前提交的分支和本次提交的校验和。
加上`-a`选项可以将已跟踪的文件暂存并提交(跳过加入暂存区的操作)。
```bash
git commit -a
```

注意加上`-a`选项要小心，有时会将不需要的文件提交。

> [!Warning]
> 使用Git提交的时候注意提交的文件中不要有自己的敏感信息。提交后会一直留在Git仓库中，除非撤销分支，克隆这个仓库的人都能拿到这个信息。
