# Git的三种状态
**已提交(committed)**：已经保存在本地数据库中。
**已修改(modified)**：修改了文件，但是还没有存到数据库中。
**已暂存(staged)**：对已修改的文件做了标记，使之在下次提交的快照中。
# Git的三个区
**工作区**：对项目的某个版本独立提取出来的内容。
**暂存区**：实际上是个文件，保存了下次要提交的文件列表信息。在Git术语中也叫**索引**。
**Git仓库目录**：Git用来保存项目元数据和对象数据库的地方。Git克隆实际上就是复制这里的数据。
