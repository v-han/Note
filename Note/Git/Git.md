# 介绍
Git是一个版本控制工具。
与其他版本控制系统(记录每个文件变更信息)不同，Git记录文件系统的一系列快照。每次Git提交时，它会对当时的所有文件创建一个快照并保存这个快照的索引。如果文件没有被修改，Git不会重新存储这个文件，而是保存一个指向之前存储文件的链接。
