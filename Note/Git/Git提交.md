# 介绍
在进行提交操作时，Git会保存一个**提交对象**(commit object)，这个提交对象会包含作者姓名和邮箱、提交信息、指向暂存内容快照的指针和指向父对象的指针(首次提交的**提交对象**没有指向父对象的指针)。
# 内容
在使用[[git add命令]]对文件进行暂存时，Git会对每一个文件进行计算校验和操作，然后以**blob对象**(Binary Large Object，二进制大对象)保存并存储到Git仓库中。

在使用[[git commit命令]]进行提交时，Git会先计算每个子目录的校验和然后将这些校验和保存为**树对象**。之后Git会创建一个**提交对象**，这个**提交对象**除了上面所列出的信息之外还会包含一个指向这个**树对象**的指针。
