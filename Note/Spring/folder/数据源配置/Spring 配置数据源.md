# 数据源(连接池)的作用
1. 提高程序性能。
2. 事先实例化数据源，初始化部分连接资源。
3. 使用连接资源时从数据源中获取。
4. 使用完毕之后将连接资源归还给数据源。

常用的数据源：DBCP，C3P0，BoneCP，Druid等。
