# 介绍
依赖注入的一种方法。
# 注入方法
`UserDao`相关的代码略。
创建业务层接口代码：
```java
package org.example.service;

public interface UserService {
	public void methon();
}
```

创建业务层实现代码：
```java
package org.example.service.impl;

import org.example.dao.UserDao;
import org.example.service.UserService;

public class UserServiceImpl implements UserService {
	
	private UserDao userDao;
	
	public UserServiceImpl(UserDao userDao) {
		this.userDao = userDao;
	}
	
	public void methon() {
		userDao.methon();
	}

}
```

在applicationContext.xml文件中添加对应的Bean：
```xml
<bean id="userService" class="org.example.service.impl.UserServiceImpl">
	<constructor-arg name="userDao" ref="userDao"></constructor-arg>
</bean>
```

> [!note]
> `<constructor-arg>`标签中的`name`元素不是userDao这个Bean名字。而是`setUserDao()`方法在set之后的字母按照驼峰命名规范的变量名。这里只是一样而已。
> `ref`元素才是Bean的名字。

在构造函数注入的普通数据类型和集合数据类型时，可以参考[[set方法依赖注入]]的这两种数据类型的注入。只需要将`<property>`标签改为`<constructor-arg>`标签。
