# 介绍
使用注解开发的时候，要在**配置文件**中配置**组件扫描**，让**Spring**知道哪个包及其子包下的**Bean**需要进行扫描和识别注解配置的类、字段和方法。
# 配置方法
使用XML时，在**配置文件**中添加以下标签，表示扫描的包：
```xml
<!-- 扫描 org.example 包下的组件 -->
<context:component-scan base-package="org.example"></context:component-scan>
```

使用注解时，在配置类上添加`@ComponentScan`表示扫描的包。
```java
@Configuration
// 扫描 org.example 包下的组件
@ComponentScan("org.example")
public class SpringConfiguration {}
```
