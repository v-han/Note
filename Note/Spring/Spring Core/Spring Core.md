# 介绍
**Spring Core**是**Spring**中用来负责**对象的创建**、**管理和对象之间的依赖关系**的部分。主要由[[IoC]]和[[DI]]的方式完成。
# 使用方式
使用前需要导入相关的依赖。
```Maven
<dependency>
	<groupId>org.springframework</groupId>
	<artifactId>spring-context</artifactId>
	<version>5.0.5.RELEASE</version>
</dependency>
```

配置一个[[Bean]]。
