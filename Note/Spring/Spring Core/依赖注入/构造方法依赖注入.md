# 介绍
使用**构造方法**为**Bean**注入所需的依赖。
# 注入方法
在**配置文件**中在`bean`标签中配置**Bean**所需的依赖。`name`属性表示要注入的元素或者使用`index`属性按构造方法的参数顺序表示需要注入的元素，`value`和`ref`表示注入的**值**和**Bean**。
```xml
<bean id="userService" class="org.example.service.impl.UserServiceImpl">
	<!-- 配置注入的普通数据类型 -->
	<constructor-arg name="username" ref="Tom"></constructor-arg>

	<!-- 配置注入的引用数据类型，即注入其他的 Bean -->
	<constructor-arg name="userDao" ref="userDao"></constructor-arg>
	
	<!-- 配置注入的集合数据类型 -->
	<constructor-arg name="strList">
		<list>
			<!-- 如果注入集合的元素是 Bean，这里用 ref 标签 -->
			<value>String1</value>
			<value>String2</value>
		</list>
	</constructor-arg>
</bean>
```

> [!NOTE]
> 使用**构造方法**注入时，需要确保需要**构造方法**中有对应的元素。
