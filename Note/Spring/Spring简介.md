# 介绍
**Spring**是分层的**Java SE/EE**应用**full-stack**轻量级开源框架，以[[IoC]]和**AOP**为内核。
提供了展现层**SpringMVC**和持久层**Spring JDBCTemplate**以及业务层事务管理等众多企业级应用技术。
# 优势
1. 方便解耦，简化开发。
2. AOP编程的支持。
3. 声明式事务控制。
4. 方便程序的测试。
5. 方便继承各种优秀的框架。
6. 降低JavaEE API的使用难度。
7. Java源码是经典学习范例。
